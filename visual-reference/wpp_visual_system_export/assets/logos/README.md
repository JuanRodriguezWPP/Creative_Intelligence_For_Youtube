## 2. Shared Optical Axis & Clear Space

The brand hierarchy follows the approved single-axis horizontal lockup:

```text
[ WPP Media Solutions ]  /  [ Creative Intelligence ]  /  [ Social ]
```

- **Alignment**: Vertically centered along a single shared optical horizontal baseline.
- **Divider**: Subtle hairline slash (`/`) with 12px horizontal clearance.
- **Clear Space**: Maintain a minimum exclusion zone equal to the height of the letter "W" around all logo marks.
- **Prohibitions**:
  - Never distort, stretch, or alter the aspect ratio of the SVG marks.
  - Never change the hue of the Signature Lime accent (`#AEF366`).
  - Never place the logos over busy photography without sufficient background contrast.
