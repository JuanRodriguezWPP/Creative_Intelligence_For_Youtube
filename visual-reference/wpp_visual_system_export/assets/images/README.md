## 2. Note on Raster Images (PNG / JPG)

The WPP Media Solutions visual system intentionally avoids reliance on decorative raster PNG/JPG illustrations or unscalable clip art. 

- **Thumbnails & Video Mockups**: The UI uses programmatic 9:16 card containers with format badges (`Meta Reels`, `TikTok`), duration tags (`15.0s`), and hook rate chips (`88.4% Hook Rate`), which dynamically adapt to client video feeds.
- **Atmospheric Backgrounds**: Generated via scalable SVG vectors and high-performance CSS radial gradients rather than heavy JPG bitmaps.
- **Logos & Icons**: Preserved in scalable SVG format for crisp rendering across Retina and High-DPI screens.
