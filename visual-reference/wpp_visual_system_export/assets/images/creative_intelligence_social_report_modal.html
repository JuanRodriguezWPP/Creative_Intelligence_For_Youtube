05 · Glosario

Entiende los términos
de Creative Intelligence.

Una sección sencilla, de consulta; no una explicación metodológica.

01 · Creative Intelligence

Creative Intelligence ScoreIndicador que resume el nivel de fortaleza creativa de una campaña o pieza según las señales analizadas.
Creative SignalsCaracterísticas observables de una creatividad, como atención, branding, claridad, copy, visual, producto, CTA o narrativa.
Creative IndexDefinición exacta a adoptar finalmente en el producto.

02 · Performance & Context

Performance IntelligenceLectura del desempeño y delivery de las creatividades en campaña.
Context IntelligenceInformación para interpretar las señales según objetivo, audiencia, marca, mercado, placement, benchmark y restricciones.
DeliveryCómo se distribuyó la inversión/exposición entre las diferentes creatividades.
BenchmarkReferencia utilizada para contextualizar el desempeño.

03 · Opportunity & Action

Opportunity IntelligenceConecta creatividad, performance y contexto para identificar y priorizar oportunidades.
KEEPMantener aquello que está funcionando.
OPTIMIZEMejorar una señal o elemento existente sin perder lo que ya funciona.
EXPLOREProbar una nueva dirección o hipótesis creativa.
Creative ServicesCapacidad para llevar recomendaciones a adaptación, desarrollo y producción de nuevas variantes.
