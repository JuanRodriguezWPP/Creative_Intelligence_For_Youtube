# Implementation Plan

**Active-markup evidence and fixed design decisions.** The live Angular component declares `templateUrl: './app.component.html'` in `src/app/app.component.ts`, and `src/app/app.component.html` contains the rendered overlay guarded by `*ngIf="isTerritoryModalOpen"`; no component, route, or loader references `src/app/modal.html`, so that untracked file is orphaned and must not be edited or copied wholesale. Implement the correction in the embedded modal, retain the valid Contexto composition, and use one responsive split-shell whose left rail changes its supporting content by tab while preserving the same territory identity. The verified API contract exposes only `foco_del_problema`, `diagnostico_video_original`, `solucion_hiperlocal`, `formato_sugerido`, and `elementos_de_adaptacion` in `V2GeoOportunidadCreativa`; therefore the UI will derive presentation models from those real fields instead of pretending that relevance scores, campaign outcomes, previews, or measured KPIs exist.
